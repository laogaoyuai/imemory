# 微信小程序 0.0.1 发布清单

这份清单区分“仓库代码已完成”和“必须使用真实主体、生产资源或微信真机完成”。当前代码版本定义为 `0.0.1`；生产发布前仍需完成真实主体、生产资源和微信真机验收。

## 自动检查

先生成生产构建，再在注入生产环境变量的终端运行：

```bash
pnpm build:mini
pnpm check:release:strict
```

严格检查包括 Node 版本、真实 AppID、合法域名校验、生产 HTTPS API、隐私联系人、内容安全模式、数据库、微信凭证、对象存储和当前主包体积。`pnpm check:release` 是不会返回失败码的本地诊断模式。

## 代码侧已完成

- 登录前展示数据用途并记录隐私说明版本；说明更新后会重新征求同意。
- 登录、相册/相机和微信会话文件入口调用微信隐私授权检查。
- “关于与隐私”页可以查看微信隐私保护指引、授权状态、运行环境和联系人配置。
- API 为每个请求生成或校验请求 ID，并在错误响应和响应头中回传。
- API 返回安全响应头，关闭框架标识，限制 JSON 请求体。
- 登录/刷新和通用接口使用不同的固定窗口限流；生产环境输出不含正文和令牌的结构化访问日志。
- 生产环境拒绝弱 JWT、本地数据库默认值、模拟微信登录、非 HTTPS 资源地址、不安全 CORS 和关闭内容安全检查。
- 用户资料、内容、评论、项目和合集的文本写入统一调用微信文本内容安全接口；接口异常时失败关闭。
- API Client 为每次请求附带请求 ID，便于客户端错误与服务端日志关联。

## 真实资源阻塞项

- [ ] 在微信公众平台完成小程序主体、名称、类目和服务内容配置，并将 `touristappid` 替换为真实 AppID。
- [ ] 在微信后台填写并审核“用户隐私保护指引”，声明实际使用的相册、相机、会话文件、账号和网络信息；配置真实客服/隐私联系人。
- [ ] 准备备案且证书有效的 HTTPS API、上传和下载域名，并加入小程序合法域名；把开发者工具 `urlCheck` 恢复为 `true`。
- [ ] 部署 PostgreSQL 和 S3 兼容对象存储，执行全部前向 Migration；完成一次备份恢复演练并记录耗时、RPO 和 RTO。
- [ ] 对上传后的图片、视频和文档执行对象存在性确认、魔数复核、病毒扫描；公开图片/视频还需接入适用的媒体内容安全检查。当前代码只完成文本安全检查，因此这是生产阻塞项。
- [ ] 多实例 API 在网关或 Redis 层配置共享限流。代码内固定窗口限流只保护单个实例，不能代替集群级防护。
- [ ] 接入错误监控、可用性探测和告警；确认日志脱敏、留存周期和访问权限。
- [ ] 准备账号注销、内容举报、违规处置和数据删除流程，并在提审材料与隐私指引中提供实际入口或联系方式。

## 真机验收矩阵

- [ ] iOS 微信：首次隐私授权、拒绝后重试、登录、退出、会话过期刷新。
- [ ] Android 微信：同上，并验证相册/相机/会话文件返回路径和权限拒绝。
- [ ] 双账号：公开分享落地、私密内容拦截、评论回复与点赞撤销。
- [ ] 三角色：项目主、管理员、成员提交审核、驳回和回退。
- [ ] 弱网/断网：发布、附件部分上传、重复点击、恢复网络、revision 冲突处理。
- [ ] 媒体：纵向长列表、视频自动播放/暂停、音频焦点、前后台切换和内存占用。
- [ ] 数据：首次登录迁移本地草稿、跨设备增量同步、删除墓碑和重新安装后的云端恢复。
- [ ] 性能：冷启动、首屏可交互、长列表滚动、连续浏览 100 条内容和包体分析。
