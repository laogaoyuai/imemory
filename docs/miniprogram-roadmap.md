# 微信小程序生产路线

## 版本目标

微信小程序 `0.0.2` 的发布目标是覆盖 iOS `0.0.2` 的产品能力，并以真实多用户、可同步的生产架构上线。内部使用 `alpha`、`beta`、`rc` 标识阶段，不占用新的正式版本号。

```text
0.0.2-alpha.1  工程骨架与本地内容闭环
0.0.2-alpha.2  微信登录、API、数据库、对象存储与离线同步
0.0.2-alpha.3  用户、项目和角色权限
0.0.2-alpha.4  内容版本、审核与回退（代码侧已完成）
0.0.2-alpha.5  合集、全屏浏览与媒体播放（代码侧已完成）
0.0.2-beta.1   评论升级、分享、异常与离线处理（代码侧已完成）
0.0.2-rc.1     安全、隐私与发布自检代码侧完成，真实资源验收中（当前）
0.0.2          生产发布
```

## Alpha 1：小程序基础闭环（已完成）

- Taro 4.2.1 + React 18 + TypeScript 6。
- 接入 `@atlas/core`，由 Taro 编译 Monorepo 中的共享 TypeScript 源码。
- Zustand 页面状态。
- 小程序 Storage Content Repository。
- 内容列表、关键词搜索和类型筛选。
- 文本、图片、多图、视频和微信会话文件发布。
- 本地文件持久化、内容详情、点赞和收藏。
- 内容版本快照存储接口。

这一阶段是可验证的开发基础，不是生产上线版本。

## Alpha 2：生产数据底座（代码侧已完成）

在 `apps/api`、`packages/contracts`、`packages/api-client` 中实现：

- NestJS API 与 PostgreSQL/Prisma。
- 微信登录凭证交换和安全会话。
- 用户、内容、附件、项目、成员、合集、评论和版本表。
- 对象存储预签名上传、MIME/魔数/大小检查。
- 幂等键、`revision`、`deletedAt`、客户端重试和冲突处理。
- 本地 Repository 与 Remote Repository 切换策略。

当前已完成：

- NestJS 11 API 工程、统一错误响应和环境校验。
- Prisma 7 PostgreSQL Schema、初始 SQL Migration 和显式生成 Client。
- 用户、会话、内容、内容版本、上传、项目成员、合集、评论和幂等表。
- `wx.login` code 交换接口以及开发环境 mock provider。
- 短期 JWT、服务端会话校验、refresh token 哈希存储与单次轮换。
- 内容增量查询、revision 乐观锁、幂等 upsert、删除墓碑和冲突响应。
- S3 兼容对象存储预签名 PUT URL、MIME 和 100 MB 大小边界。
- 跨端 Zod API 契约、自动刷新 API Client 和 Taro Transport。
- 小程序本地/云端会话状态入口与按账号隔离的本地缓存。
- 可复用 Sync Coordinator，按“推送本地队列—拉取远端增量”执行同步。
- 未登录草稿首次登录迁移、revision 元数据、删除墓碑和 UUID 幂等队列。
- 附件预签名 PUT 上传；部分附件成功后会持久化进度，失败可继续重试。
- 登录、发布、点赞、收藏、阅读和下拉刷新触发自动同步。
- 断网保留本地修改，首页展示待同步数量、错误状态和手动重试入口。
- revision 冲突不会静默覆盖，首页支持“保留本地”或“采用云端”。
- 同步协调与小程序队列/冲突策略已经加入自动化测试。

接入真实生产资源后完成：

- 在托管 PostgreSQL 执行 migration，并验证备份恢复。
- 配置真实微信 AppID/Secret 和合法 API 域名。
- 配置 S3/R2/COS 等对象存储、上传回调、魔数检查和恶意文件扫描。
- 为大于 20 MB 的小程序附件实现分片与断点续传；当前版本会明确阻止高内存整文件上传。

## Alpha 3：用户与团队项目（代码侧已完成）

- 用户显示名称、简介的读取与修改。
- 用户主页、关注/取消关注、粉丝与关注数量。
- 用户搜索以及私密项目邀请入口。
- 创建公开/私密项目，创建者自动成为项目主。
- 公开项目发现、关注和取消关注；不同账号数据由服务端隔离。
- 项目主页展示项目主、管理员/成员/粉丝/内容统计。
- 项目主可修改项目信息、调整全部角色并转让项目。
- 管理员只能在成员和粉丝之间调整，不能任命管理员或转让项目。
- 成员拥有内容协作权限；粉丝可发布讨论内容但不拥有协作权限。
- 内容通过 UUID 关联项目，服务端校验发布者确实属于项目，并用真实项目名覆盖客户端展示名。
- 非项目成员访问公开项目时，只能看到标记为公开的项目内容。
- 新增 `user_follows`、`content_projects` 数据表和前向 Migration。
- Core 权限规则、项目服务及用户关注服务均有自动化测试。

真实数据库执行 Migration 并完成双账号真机联调后，才视为生产验收完成。

## Alpha 4：内容版本闭环（代码侧已完成）

- Core 提供语义版本比较、补丁版本递增，以及编辑、审核和自动通过规则。
- 内容编辑会生成高于全部历史记录的新版本；同版本的点赞、收藏、阅读同步不会重写历史快照。
- 个人内容和项目主/管理员提交的项目内容自动通过；成员或粉丝提交的项目内容进入待审核。
- 内容同时关联多个项目时，审核者必须在每个项目中都是项目主或管理员。
- 驳回当前版本会恢复最近一个已通过快照；只允许回退到已通过版本，历史记录继续保留。
- 小程序内容详情已开放编辑和版本历史入口，版本页支持状态展示、基于历史编辑、通过、驳回与回退。
- API、Prisma 前向 Migration、共享契约、API Client 和小程序账号缓存同步元数据已经贯通。
- 未加入项目的访问者看不到待审核或已驳回内容。

真实数据库执行 Alpha 4 Migration，并完成创建者、成员和管理员三账号联调后，才视为生产验收完成。

## Alpha 5：个人合集与连续浏览（代码侧已完成）

- 个人合集改为服务端账号数据，支持创建、封面上传、修改和删除。
- 合集只允许加入本人创建、未关联项目并且与合集类型一致的内容。
- 内容标识去重，服务端使用连续 `position` 持久化管理页的上下排序结果。
- 小程序首页新增个人合集入口，管理页可增删内容、切换类型和调整顺序。
- 使用纵向 Swiper 实现一屏一条的连续浏览，并可从指定内容进入对应位置。
- 当前页视频自动播放，离页主动暂停；音频上下文仅在当前页创建，离页销毁。
- 视频或音频播放结束后自动推进下一条；图片支持微信原生预览。
- 合集所有权、内容类型及个人内容约束已经加入 Core 与 API 自动化测试。

合集表在初始 Migration 中已经存在，本阶段启用了对应 API。仍需在微信 iOS/Android 真机验证自动播放策略、音频焦点和长列表内存。

## Beta 1：评论、分享与异常处理（代码侧已完成）

- API 提供可见内容读取、评论列表、发表评论、回复、评论点赞切换和分享计数接口。
- 新增 `comment_likes` 关系表，按用户记录点赞状态并支持撤销，避免只有不可靠的总数。
- 发表评论和分享后由服务端递增内容指标及 revision，客户端接收权威内容快照。
- 内容详情页支持分享路径加载、未登录引导、加载失败重试、完整评论列表、回复和点赞。
- 公开内容生成微信好友及朋友圈分享信息，分享路径直接落到对应内容详情。
- 合集浏览页增加高赞优先的评论轮播、完整评论面板、回复和点赞。
- 视频加载失败给出网络重试提示，音频失败后允许点击重试；API Client 延续 401 刷新和单次重试。
- 私密内容、待审核内容和项目成员内容继续使用服务端可见性校验，分享标识不能绕过权限。

真实数据库需要执行 Beta 1 Migration，并使用至少两个微信账号验证公开分享、私密拦截、回复与点赞撤销。

## RC 1：生产验收

代码侧已完成：

- 登录知情同意版本记录、微信隐私授权检查和“关于与隐私”页面。
- 相册、相机、会话文件入口在调用前检查微信隐私授权。
- API 请求 ID、安全响应头、请求体限制、登录/通用接口分级限流和结构化访问日志。
- 生产 HTTPS/CORS、真实微信登录、强密钥、对象存储和文本内容安全的启动校验。
- 用户资料、内容、评论、项目与合集写入前调用微信文本内容安全接口，异常时失败关闭。
- `check:release` 诊断和 `check:release:strict` 严格发布门禁。

仍需真实资源完成：

1. iOS/Android 微信真机、弱网、媒体焦点、长列表和包体测试。
2. 微信后台隐私指引、真实主体联系人、媒体安全审核、举报和违规处置。
3. 集群共享限流、监控告警、备份恢复、Migration 演练和提审材料。

完整清单见 `docs/miniprogram-release-checklist.md`。

每个闭环必须同时包含 Core 规则、API、持久化、小程序 UI 和自动化测试。

## Beta/RC：生产门槛

- 使用真实小程序 AppID，区分开发、体验和生产环境。
- 隐私协议、用户信息授权、内容安全审核和违规处理。
- 弱网、断网、重复提交、上传失败和会话过期恢复。
- 主包/分包体积、首屏时间、长列表和媒体内存检查。
- 微信开发者工具、iOS 微信真机、Android 微信真机回归。
- API 限流、日志、监控、备份和数据库迁移演练。

## 小程序上线后的版本规则

- `0.1.0`：首批小程序优先的新产品能力。
- `0.1.x`：兼容性修复和小改进。
- `0.2.0`：下一批明显的新能力。
- iOS、Web 和小程序版本号互不绑定，以能力矩阵表达差异。
